# Тайлангийн формат ба хэвлэлийн шалгалт

Эцсийн шалгалт: 2026-09-14. Гаралт: `report/main.pdf`, **40 A4 хуудас**.

## Диаграм буцаасан шинэчлэлт

Хэрэглэгчийн хүсэлтээр 10 диаграмыг өмнөх дэлгэрэнгүй Mermaid төрхөд буцаав. Тайланд анхны хадгалсан PNG зургуудыг холбоод, зургаан хялбарчилсан эх/PDF, хэвлэлийн тусгай theme/config/CSS-ийг хассан. Анхны арван `.mmd` эх өөрчлөгдөөгүй. Одоогийн Mermaid-аар дахин үүсгэхэд RAG-ийн байрлал өөрчлөгдөж байсан тул өмнөх төрхийг яг хадгалахын тулд анхны PNG-уудыг ашиглав.

Зураг `[!htbp]`, `placeins[section,above,below]`; зураг–текст 8–10 pt, caption-ийн өмнө 5 pt, дараа 2 pt тохиргоотой. Анхны өргөнийг сэргээж, тайлан 44-өөс 40 хуудас болсон. Бусад баталсан формат, зурагнаас гадуурх бичвэр, хүснэгт, кодыг өөрчлөөгүй.

`pnpm report:build`, `bash -n report/figures/build.sh` амжилттай. 40 хуудасны render-ийг үзсэн; хуудаснаас хальсан үг, overfull box, oversized float, missing glyph, unresolved reference/citation байхгүй. Анхны Mermaid эхүүд болон зассан бүлгүүдийн зурагнаас бусад агуулгыг өөрчлөхийн өмнөх хуулбартай харьцуулсан.

**Одоогийн зургууд raster PNG; доорх өмнөх вектор/8.5 pt хэмжилт одоогийн PDF-д хамаарахгүй.** Анхны жижиг бичвэр, нягтаршлын хязгаар мөн буцсан. `build.sh` нь default Mermaid theme болон анхны эх ашиглана; анхдагч гаралт PNG, `bash report/figures/build.sh pdf` нь optional PDF. Дахин render хийвэл хуучин экспорттой layout ялгаатай байж болох тул солихоос өмнө заавал үзэж шалгана.

## Баталсан формат

| Зүйл | Хэрэгжсэн байдал |
|---|---|
| Зах | Зүүн 3 см, баруун 2 см, дээр 2.5 см, доор 2 см; `includefoot` |
| Үндсэн текст | 12 pt; мөрийн зай 1.0 хэвээр |
| Бүлгийн гарчиг | 16 pt / 20 pt baseline, автомат мөр шилжилт; зах дотор |
| Фонт | TNR хүсэлттэй боловч бодит TNR/Arial суулгаагүй: Liberation Serif/Sans орлуулалттай |
| Удиртгал | Тусдаа, нэг нүүр; зорилго, хүрээ, бүтэц орсон |
| Жагсаалтууд | Агуулга, зураг, хүснэгт, кодын автомат жагсаалт |
| Дүгнэлт | Дугааргүй; дэд хэсгүүд мөн дугааргүй |
| Хавсралт | «Өгөгдлийн сан ба кодын хэрэгжүүлэлт», A дугаарлалт |
| Кодын тайлбар | Үндсэн бүлэг болон хавсралтад доор |
| Ном зүй | `nocite{*}` байхгүй; бичвэрт ишилсэн найман эх сурвалж |
| Хөтөлбөр | «Програм хангамж» |

## Өмнөх 44 хуудасны вектор хувилбарын түүхэн шалгалт

- Тайланд ашигласан **10 диаграм бүгд вектор PDF**, дотор нь raster зураг байхгүйг `pdfimages -list`-ээр шалгав. PDF-ийн фонтууд embedded тул өөр компьютерт нээхэд фонтын орлуулалт үүсэх эрсдэлийг бууруулсан.
- Хуучин чатын өргөн диаграмыг 16 см өргөнд хэвлэхэд үсэг ойролцоогоор 3 pt болж байсан. API доторх үйлдлүүдийг нэг оролцогчид нэгтгэсэн хэвлэлийн хувилбар гаргав; тухайн зураг үүнийг тайлбартаа илэрхийлнэ.
- Архитектур, системийн хүрээ, нэвтрэлт, deployment, ER-д мөн `*-print.mmd` хувилбарууд бий. Дэлгэрэнгүй Mermaid эхүүд хадгалагдсан. ER-ийн зураг гол хүснэгтүүдийн холбоосыг харуулна; бүх багана болон бодит SQL хавсралтад байгаа. Нэвтрэлтийн SQL-ийг тусдаа эх файлаар заасан хэвээр.
- PDF текстийн хэмжээ болон оруулах scale-аас тооцсон хамгийн жижиг диаграмын үсэг ойролцоогоор **8.5 pt-аас дээш**. Энэ нь эхийн хэмжилт; бодит принтерээр туршилтын хэвлэл хийгээгүй. Эцэслэн хэвлэхдээ A4, Actual size / 100% ашиглах.
- Өнгөөс дангаар хамаарахгүй, цайвар саарал дэвсгэр, бараан шугам/үсэг бүхий хэвлэлийн theme ашиглав. Цагаан толгойтой note хайрцгуудын бараан дэвсгэрийг хадгалсан.
- Нүүрний одоогийн лого 450×450 px, 6 см өргөнд ойролцоогоор **190 ppi**. Диаграмуудтай адил вектор биш тул ойроос харахад зөөлөрч болно. Сургуулийн ZIP-ийн лого өөр дүрслэлтэй учраас одоогийн албан тэмдгийг түүнээр солиогүй; яг ижил логоны өндөр нягтаршилтай/вектор эх ирвэл солих боломжтой.

## Өмнөх хувилбарт шалгасан зүйл

- `pnpm report:build` амжилттай; `Overfull`, `Missing character`, undefined reference/citation байхгүй.
- Бүх хуудасны render-ийг тоймлон шалгасан; нүүр, жагсаалт, хүснэгт, диаграм, сүүлчийн кодын хуудсыг тусад нь үзсэн. Footer-ийн үсгийн бодит хүрээг тооцсон page-bound шалгалтаар хальсан үг байхгүй.
- Хавсралтын `processDocument`, `rerankWithMmr` кодын агуулга одоогийн source-той яг таарч байна. Байршлыг засахдаа кодыг өөрчлөөгүй.
- Урт identifier-уудад мөр таслах боломж нэмсэн, зураг `[htbp]` байрлалтай бөгөөд хэсгийн хил давуулахгүй `placeins` хэрэглэсэн. MMR listing-ийн өмнөх албадсан шинэ хуудсыг шаардлагатай зай шалгах `Needspace` болгож сольсон; хавсралтын code leading-ийг локалаар тохируулсан.
- `report/figures/build.sh` нь Mermaid CLI 11.17.0, `print-config.json`, `print.css` ашигладаг. Анхдагч гаралт PDF; `bash report/figures/build.sh png` гэж PNG үүсгэж болно.
- Програмын код өөрчлөгдөөгүй тул өмнөх амжилттай typecheck/build-ийг давтаагүй. Энэ удаа DB, Gemini API, cloud deployment ажиллуулаагүй.

## Үлдсэн зүйл

1. Жинхэнэ Times New Roman/Arial файлууд: одоогоор Liberation орлуулалттай. Фонт солигдвол хуудасны багтаамжийг дахин шалгана.
2. Бодит web/mobile screenshot: одоогоор файл байхгүй, тайланд зохиомол дэлгэцийн зураг нэмээгүй. Docker/API/device runtime blocker нь тусдаа бүртгэлтэй.
3. Гарын үсэг/тамгатай үнэлгээ, захирлын тушаал, бодит огноо/оноо болон эцсийн хэвлэлийн хяналт.
