# C4 Model

C4-ийн эхний хоёр түвшин. Түвшин 3 (Component)-ийг тусад нь зурахгүй — серверийн модулиудын задаргаа `report/figures/architecture.png` болон CLAUDE.md-ийн модулийн хүснэгтэд аль хэдийн бий.

## Level 1 — System Context

```mermaid
C4Context
    title RAG Chatbot — System Context

    Person(user, "Хэрэглэгч", "Байгууллагын ажилтан / оюутан — баримтдаа асуулт асууна")

    System(rag, "RAG Chatbot систем", "Байршуулсан баримтад суурилан асуултад хариулж, эх сурвалжаа ишилдэг. Монгол хэлний бүрэн дэмжлэгтэй.")

    System_Ext(gemini, "Google Gemini API", "Embedding (gemini-embedding-001) + generation (gemini-2.5 гэр бүл). Үнэгүй түвшин — цорын ганц гадаад хамаарал.")

    Rel(user, rag, "Баримт байршуулна, асуулт асууна", "HTTPS — вэб/мобайл")
    Rel(rag, gemini, "embedContent / generateContent", "HTTPS REST")

    UpdateLayoutConfig($c4ShapeInRow="2", $c4BoundaryInRow="1")
```

## Level 2 — Containers

> Тайлангийн Зураг 4.1 (`architecture.png`) энэ түвшнийг илүү дэлгэрэнгүй (модулиудтай нь) харуулдаг тул энэ хувилбар зөвхөн docs-д байна — давхардуулахгүй.

```mermaid
C4Container
    title RAG Chatbot — Containers

    Person(user, "Хэрэглэгч")

    System_Boundary(rag, "RAG Chatbot") {
        Container(web, "Web App", "React + Vite + Tailwind", "Landing + workspace, glassmorphism, монгол UI")
        Container(mob, "Mobile App", "Expo + React Native + NativeWind", "Onboarding, чат, баримт — вэбтэй бүрэн parity")
        Container(api, "API", "Fastify + TypeScript (ESM)", "Domain модулиуд: documents, ingestion, retrieval, chat, conversations + Better Auth in-process")
        ContainerDb(db, "Database", "PostgreSQL 16 + pgvector", "Бүх өгөгдөл: app 5 хүснэгт + auth 4 хүснэгт, VECTOR(768) + HNSW")
    }

    System_Ext(gemini, "Gemini API", "embedding + generation, үнэгүй түвшин")

    Rel(user, web, "ашиглана", "HTTPS")
    Rel(user, mob, "ашиглана")
    Rel(web, api, "JSON/HTTP + session cookie", ":4000")
    Rel(mob, api, "JSON/HTTP + SecureStore cookie", ":4000")
    Rel(api, db, "SQL (pg Pool, ORM-гүй)", ":5432")
    Rel(api, gemini, "REST", "HTTPS")

    UpdateLayoutConfig($c4ShapeInRow="2", $c4BoundaryInRow="1")
```
